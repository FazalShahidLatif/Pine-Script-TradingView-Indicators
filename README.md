# Pine Script TradingView Indicators

Custom TradingView Pine Script indicators for XAUUSD, forex, and crypto trading.

## Indicators

### 1. XAUUSD Signal Assistant
- Entry/exit signals for gold trading
- Risk management levels (SL/TP1/TP2/TP3)
- Trend direction indicator
- Support/resistance levels

### 2. Multi-Timeframe Trend Analyzer
- Trend detection across 3 timeframes
- Buy/sell/neutral signals
- Visual trend strength meter

### 3. Volatility Breakout Detector
- ATR-based volatility measurement
- Breakout signals with confirmation
- False breakout filtering

## Usage

1. Open TradingView Pine Editor
2. Copy the indicator code
3. Add to chart
4. Configure settings as needed
